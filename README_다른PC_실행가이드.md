# 🔬 Display Foresight - 다른 PC 실행 및 자동수집 설정 가이드

본 프로젝트는 **어떤 PC(Windows / macOS / Linux / 사내 서버)**에서도 그대로 복사해 열거나, 네트워크를 통해 원격 접속할 수 있도록 패키징되어 있습니다.

---

## 1. 다른 PC에서 여는 3가지 방법

### 방법 A. 같은 와이파이 / 사내망의 다른 PC·태블릿에서 바로 접속 (설치 불필요)
현재 대시보드가 실행 중인 PC와 동일한 네트워크(사내 LAN 또는 Wi-Fi)에 연결된 다른 PC나 태블릿에서는 아무것도 설치할 필요 없이 웹 브라우저 주소창에 아래 주소를 입력하면 즉시 열립니다:
* 접속 주소: 대시보드 좌측 사이드바 하단 **`🖥️ 다른 PC에서 열기 / 포터블 배포`** 메뉴에 표시된 `http://<현재PC_IP>:8501`

### 방법 B. 다른 PC(Windows / Mac)로 파일 통째로 옮겨서 실행
1. 대시보드 좌측 사이드바의 **`[📦 다른 PC 이동용 전체 패키지(.zip) 다운로드]`** 버튼을 눌러 압축 파일을 다운로드하거나, `display_foresight` 폴더 전체를 USB/클라우드로 다른 PC에 복사합니다.
2. 압축을 푼 뒤 운영체제에 맞는 실행 파일을 **더블클릭**합니다:
   * **Windows PC**: `start_windows.bat` 더블클릭 (필수 라이브러리 자동 설치 후 브라우저 오픈)
   * **Mac PC**: `start_mac.command` 더블클릭 (필수 라이브러리 자동 확인 후 브라우저 오픈)

### 방법 C. Docker 컨테이너로 서버/PC에 상시 구동
Docker가 설치된 환경에서는 아래 명령어 한 줄로 백그라운드 상시 실행(새벽 04:00 자동수집 포함)이 가능합니다:
```bash
docker compose up -d --build
```

## 2. API 키 나중에 별도 등록하는 방법 (2가지 중 택 1)

API 키(`OPENAI_API_KEY`, `KIPRIS_API_KEY`)는 지금 당장 없어도 대시보드 열람 및 USPTO(미국 특허)·글로벌 뉴스 수집이 가능하며, **나중에 언제든 아래 두 가지 방법 중 편한 방식으로 등록**할 수 있습니다.

1. **웹 화면에서 바로 등록 (권장)**
   * 대시보드 좌측 사이드바 하단의 **`⚙️ API 키 & 새벽 04:00 자동수집 설정`** 메뉴를 엽니다.
   * `OpenAI API Key` 또는 `KIPRIS API Key` 입력란에 키를 붙여넣고 **`[💾 API 키 저장]`** 버튼을 누르면 `.env` 파일에 즉시 반영됩니다.
2. **파일에 직접 입력**
   * 프로젝트 폴더 내 `.env` 파일을 메모장(텍스트 에디터)으로 열어 아래 항목에 키를 입력 후 저장합니다.
     ```env
     OPENAI_API_KEY=sk-...
     KIPRIS_API_KEY=...
     ```

## 3. 매일 한국시간(KST) 새벽 04:00 자동 수집·분석 동작 원리

본 시스템은 **이중 스케줄러**를 지원합니다:
1. **대시보드 내장 스케줄러 (기본 탑재·자동 가동 중)**
   * 대시보드(`main.py`)가 켜져 있으면 백그라운드 데몬이 한국 표준시(`Asia/Seoul`, UTC+9) 기준 **매일 새벽 04:00** 정각에 자동으로 5단계 파이프라인(특허 수집 → 뉴스 수집 → 키워드 추출 → 델타 3줄 요약 & 이상기류 탐지 → 임원 브리핑 생성)을 실행합니다.
   * 원할 때 언제든 사이드바의 **`[🚀 지금 즉시 수집·분석 실행]`** 버튼으로 수동 실행할 수도 있습니다.
2. **운영체제(OS) 스케줄러 등록 (대시보드를 꺼두었을 때도 새벽 04:00 실행)**
   * **Windows**: `setup_schedule_windows.bat` 우클릭 → 관리자 권한으로 실행 (Windows 작업 스케줄러 등록)
   * **Mac**: `setup_schedule_mac.command` 실행 (`crontab` 새벽 04:00 KST 등록)
